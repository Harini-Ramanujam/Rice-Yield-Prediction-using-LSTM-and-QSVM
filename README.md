# Rice-Yield-Prediction-using-LSTM-and-QSVM

An intelligent smart agriculture web application that combines **Deep Learning** and **Quantum Machine Learning** techniques for **Rice Yield Prediction**.

This project implements a hybrid **LSTM + QSVM (Quantum Support Vector Machine)** approach to improve agricultural prediction systems and assist in smarter farming decisions.

# Project Modules

## 1. Rice Yield Prediction

The system predicts rice yield using agricultural parameters such as:

* Rainfall
* Temperature
* Humidity
* Soil pH
* Fertilizer Usage
* Soil Moisture
* Sunlight Intensity

The prediction model combines:

* LSTM (Long Short-Term Memory)
* QSVM (Quantum Support Vector Machine)

The application also provides recommendations to improve crop yield efficiency.

---

## 2. Rice Leaf Disease Detection

The system detects rice leaf diseases using a trained **MobileNetV2 CNN model**.

### Diseases Detected

* Bacterial Leaf Blight
* Brown Spot
* Leaf Blast
* Leaf Scald
* Narrow Brown Spot

Users can upload rice leaf images and receive real-time disease predictions with confidence scores.
